# Dipak Patil — Interactive Portfolio

## Included
- `index.html` — portfolio structure/content
- `styles.css` — responsive premium dark/light design
- `script.js` — theme switcher, mobile menu, scroll animations, skill/project filters
- `assets/Dipak_Patil_Resume.pdf` — portfolio resume PDF

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Create a repository named `Dipakpatil2282.github.io`.
2. Upload all files/folders from this package.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
4. Your website will be available at `https://Dipakpatil2282.github.io`.
